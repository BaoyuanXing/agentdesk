# AgentDesk

AgentDesk is a desktop made of small agent boxes. Each box can sit quietly on the workspace, be dragged around, expand into a terminal-like agent CLI, and connect with other boxes to share context.

The app is intentionally web-first so it can move quickly, while keeping a shape that can later be wrapped with Tauri for local files, shell tools, notifications, and OS-level integrations.

## What is here

- Multiple small agent boxes on a desktop workspace.
- Draggable collapsed boxes that expand into terminal-like agent CLIs.
- Agent selection and connection so two or more agents share context.
- Local runtime API for creating and monitoring runs.
- Real persisted state under `.agentdesk/`.
- Markdown artifacts generated by completed runs.
- Built-in slash commands for `/typecheck` and `/codex`.
- Vite + React + TypeScript developer setup.
- Browser-only implementation today, with room for a future `src-tauri` shell.

## Getting started

```bash
npm install
npm run dev:real
```

Then open the local URL Vite prints, usually `http://localhost:5173`.

`dev:real` starts both pieces:

- AgentDesk runtime: `http://127.0.0.1:8787`
- Vite UI: `http://127.0.0.1:5173`

Use it like this:

1. Drag a small agent box to place it.
2. Click `Expand` to open that agent's CLI window.
3. Type an objective or use a slash command.
4. Click `Select` on two boxes, then `Connect Selected`.
5. Connected boxes share recent terminal context when launching work.

```text
/typecheck
/codex review this repository and suggest next steps
```

Completed runs create markdown reports in `.agentdesk/artifacts/`, and the console links to the latest artifact.

The current runtime shows a shell-like transcript: the command you typed, the accepted run, live stdout/stderr chunks from the underlying command, final status, and artifact link. It is not yet a full interactive PTY where a spawned program can ask follow-up questions mid-command; that is the next Tauri/runtime step.

## Scripts

```bash
npm run dev        # start the development server
npm run dev:real   # start the local runtime and Vite UI together
npm run server     # start only the AgentDesk runtime API
npm run build      # type-check and build production assets
npm run preview    # preview the production build
npm run typecheck  # run TypeScript only
```

## Product direction

AgentDesk should become a lightweight desktop where each agent is a small operable object. You can keep several tiny agent boxes visible, expand any one into a CLI-style session, and connect boxes when you want agents to coordinate around shared context.

Likely next steps:

- Add a true always-on desktop wrapper with Tauri.
- Persist box placement, expanded state, and context connections.
- Make connections visual with lines between boxes.
- Introduce an app registry for agent tools such as browser, files, terminal, docs, and review.
- Add an approval queue for file-changing runners.
- Harden the Codex runner around authentication, permission profiles, and artifact capture.
- Add a Tauri shell when local capabilities are needed.
- Model artifacts as first-class files that can be opened, compared, exported, and handed between agents.

## Tauri path

The current project can stay as the frontend package. A future Tauri integration can add:

```text
src-tauri/
  Cargo.toml
  tauri.conf.json
  src/
```

The frontend can continue to run through Vite, while Tauri provides secure local capabilities through explicit commands.
